# Swarit Verma — Portfolio

Personal portfolio site built for the Metis (Development Club) Induction Hackathon 2026-27, IIT Gandhinagar.

Static site — plain HTML, CSS, and JavaScript, no build step. Deployed via GitHub Pages.

## Sections

- **Home** — intro
- **About** — skills & tools
- **Projects** — Portfolio site, [Earth Sciences department capstone site](https://github.com/Myst-SS/earth-sciences-site), and a work-in-progress project
- **Contact** — email, GitHub, Codeforces

## Run locally

Just open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

## Deploy

Push to a repo named `Myst-SS.github.io` and enable GitHub Pages (Settings → Pages → Source: `main` branch, `/root`). It will be live at `https://myst-ss.github.io/`.
